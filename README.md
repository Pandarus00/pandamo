# Pandamo

**Find your calm.**

Mobile Yoga- und Bewegungsbegleitung mit animiertem Panda, deutscher Sprachausgabe und lokal gespeichertem Fortschritt.

## Installation auf dem iPhone

1. Die veröffentlichte GitHub-Pages-Adresse in Safari öffnen.
2. Auf **Teilen** tippen.
3. **Zum Home-Bildschirm** auswählen.

Pandamo speichert den Trainingsfortschritt ausschließlich im lokalen Browser-Speicher des Geräts. Die App ist eine allgemeine Bewegungsbegleitung und ersetzt keine medizinische oder physiotherapeutische Beratung.
